# Universal Crafting Framework

Universal Crafting Framework is an SKSE plugin for Skyrim Special Edition, developed in C++ using CommonLibSSE-NG.

The project focuses on extending and customising crafting station functionality through native game code.

## Crafting Stations

The project includes modules for the following crafting stations:

- **Forge**
- **Grindstone**
- **Smelter**
- **Tanning Rack**
- **Workbench**

## Technical Information

- Language: C++23
- Framework: CommonLibSSE-NG
- Plugin system: SKSE
- Build system: xmake
- Development environment: Visual Studio 2026

## Building

The source code is available in the `src` directory.

CommonLibSSE-NG is required to build the project and is not included in this repository.

The local `lib`, `build`, `.xmake` and `.vs` directories are excluded from version control.

## Development Status

This project is under development. Features, behaviour and compatibility may change as development progresses.
